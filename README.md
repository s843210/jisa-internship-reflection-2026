# JISA 인턴십 활동 기록

임보현의 US Medical Inc. 일본 인턴십 후기와 현장 기록을 담은 한·일 이중 언어 웹사이트입니다.

공개 사이트: <https://s843210.github.io/jisa-internship-reflection-2026/>

## 로컬 실행

```bash
npm install
npm run dev
```

## GitHub Pages 정적 출력

```bash
npm run export:pages
```

`docs/` 폴더가 GitHub Pages 게시용 결과물입니다. 저장소의 Pages 설정은 `main` 브랜치의 `/docs` 폴더를 사용합니다.
